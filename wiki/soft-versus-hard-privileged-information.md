# Soft versus hard privileged information

Privileged information (PI) is text given to a teacher and withheld from a student. For distillation the feature that matters is not whether the PI is informative but how strongly it limits what may follow. Hard PI constrains generations structurally: "Hard PI constrains generations structurally" — a fact such as the answer makes most responses incoherent unless they produce it, so the student cannot ignore it.[^c1] Soft PI "biases preferences but admits many valid continuations": a rubric item that says a patient should be advised to find a provider pushes the teacher toward including that advice and leaves style, structure and content open.[^c2]

The difference shows in how the teacher spreads its probability. The authors score the teacher's per-token negative log-likelihood on a gold completion and on other responses that satisfy the rubric. Under hard reference PI the gold is more probable per token than the other valid responses (by 1.18 nats); under soft rubric PI it is less probable (by 0.70 nats).[^c3] The summary is that "Reference PI piles mass on one arbitrary point in the valid set; rubric PI spreads it across the set the student is exploring."[^c4] The mechanism is the one the authors give for a reference completion being a poor target: it is "one point in a set of valid responses, so distilling towards it over-constrains the student."[^c5] A rubric, by contrast, names the preference structure that many valid responses share, so the signal is "diffuse under soft PI, spread across many good completions rather than concentrated on one."[^c6]

Concentration matters for the signal the student actually gets, because distillation is computed on the student's own text. On the untrained Qwen2.5-7B-Instruct base, scored on student rollouts, "rubric conditioning produces 1.7× more per-token KL than reference conditioning."[^c7] The comparison reverses on gold completions. "Rubric PI induces similar KL on student roll-outs and on gold completions," while "reference PI induces far larger KL on the gold than on student roll-outs."[^c8] So a reference completion looks more powerful when read at the gold, and that is the wrong place to read it: "reference PI looks more powerful when scored at the gold."[^c9] Reading the same thing in terms of the asker's side (my inference, not the paper's claim): a constraint that fixes one answer narrows the answer space to a point, while a preference narrows it to a region, and only the region leaves the student room to find its own route through it.

The authors also show the on-policy part is needed and not just the rubric content. Offline supervised fine-tuning on the same rubric information does not recover the gain: "the onpolicy dense-KL mechanism, along with the rubric content, is what makes RuPI work."[^c10]

A second study, on rubric-guided self-distillation (RGSD), puts a self-generated, rubric-conditioned reference response into the teacher's context in place of the rubric, and the comparison points the same way, though it measures end-of-training scores rather than KL. On medical the rubric teacher scores higher, "a gap of 2–3 percentage points" over the reference variant.[^c16] The authors read this as coverage: "single reference response is one sampled realization of the rubric," and it "may omit criteria, overcommit to one explanation structure."[^c17][^c18] The score comparison does not test the per-token spread directly, so it supports the argument only indirectly (my inference).

## Limits

- The evidence is one benchmark family, HealthBench with physician-written rubrics, and a replication on RubricHub Science evaluated on ResearchQA. The claim is scoped: soft rubric PI beats hard PI "in this regime", meaning open-ended generation.[^c11] The verifiable case the introduction contrasts with, such as math with ground-truth answers, is background, not something this work measures.
- "Valid" is operational. The valid set is "a diverse set of other rubric-satisfying responses," generated by a model and judged against the rubric, so it is only as good as that judge.[^c12] The concentration figures come from one teacher, Qwen2.5-7B-Instruct, over 423 held-out prompts; a second candidate generator gives a similar ratio, which is what the authors offer as robustness.[^c13]
- The hard/soft distinction is a two-way description with no threshold. "How strongly it constrains" is qualitative in the paper. The NLL gap is one measurement of it, not a definition, and nothing in the work varies hardness directly while holding everything else fixed. The link from concentration to a weaker learning signal is the authors' argument from these measurements, not an ablation of concentration.
- Each configuration was trained once: "Each configuration was trained once."[^c14] Differences of about 0.01 "should be treated as within noise";[^c15] the margin over the GRPO baseline on the 7B model is in that range.
- Whether a rubric written by a person in a different domain carries the same spread is not tested beyond the two HealthBench-style settings.
