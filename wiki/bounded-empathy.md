# Bounded empathy

> A structural (not noise-based) account of why an agent modelling another through its own concepts can be confidently, undetectably wrong about one specific shared idea — until an action finally exposes it.

## Definition / Mechanism

Two agents can share a public label $\ell$ (e.g. "serious", "pain") while holding different private representational bases for it. Agent $A$ simulates agent $B$ by running its own regimes restricted to the labels they share, producing a predicted active set expressed in labels; it cannot access $B$'s actual basis. Amornbunchornvej derives three properties of the resulting error as a structural consequence of this private-basis premise, not as an inference bias: it is **forced** — the same observer must commit it, holding its configuration and the content fixed — **self-invisible** — because two bases separated by a nonzero angle can still project a given content to the same licensed action, so agreement on some inputs does not certify basis alignment — and **localized** to the one shared label whose subspaces diverge, not a general failure of "understanding."[^c1]

The error surfaces only once some later content drives the diverging bases to different licensed actions; until then $A$ observes only agreement and records confirmation.[^c2]

## Why it matters

Standard theory-of-mind accounts (inference, simulation) attribute persistent misunderstanding to noise, limited data, or a biased inference process, which requires positing a separate error model for an error the modeller cannot itself detect. This account instead predicts, from the architecture alone, that an asking or answering agent relying on observed behavioural agreement to certify that it has understood another party's concept can be wrong on exactly one concept and have no internal signal of it — output-agreement is not evidence of representational agreement, and only an explicit probe on the diverging coordinate (not further passive observation) can surface the mismatch.

## Limits

This is presented by the source as a falsifiable prediction of the model, not an established result: it rests on the private-basis premise (shared label, differing coordinate/basis assignment) and on holding the modelling agent's configuration and the label set fixed; the paper supports it with worked hand examples (two clinicians, a user and a writing assistant) and one small synthetic implementation, not with data from real human or agent misunderstanding. It is an unreviewed 2026 preprint. [?]
