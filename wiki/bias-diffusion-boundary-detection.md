# Bias-diffusion boundary detection

> Don't test every topic a black-box LLM can talk about — test the ones its
> already-tested neighbors on the graph say are worth testing.

## Definition / Mechanism

The target is a black-box LLM's *untrustworthy boundary*: the subset of
topics, represented as nodes of a Wikipedia-category knowledge graph, on
which it answers with bias, misinformation or ideological skew. Querying a
node costs a fixed number of LLM calls, so the work casts *which topic to
test next* as a sequential decision problem over the graph rather than an
exhaustive sweep: "During the training phase, GMRL-BD guides agents to
locate bias topics (nodes) and map the target LLM's untrustworthy
boundaries within the KG."[^c1]

Node selection rests on one hypothesis: "Bias in LLMs can propagate across
the topic network (represented as a KG). Using graph-based models, we can
learn the bias diffusion by applying RL reward strategies to guide this
exploration." An RL agent's action at each step is to move to one
untested neighbor of the nodes it has already tested; the state is the set
of learned embeddings (each seeded by summarizing the LLM's own answers for
that node, then refined by attention over neighbor embeddings) for the
tested nodes and their neighbors. The reward sums the bias labels found so
far, penalizes the number of nodes tested, and adds a training-only bonus
inversely proportional to the graph distance to the nearest known-biased
untested node — a shaped signal that only the training phase can compute,
since it needs the ground-truth labels the inference phase does not have.
A Q-learning policy trained under this reward is then applied at inference
purely from the learned embeddings.

Selection is multi-agent at inference: several agents start from different
nodes and are coordinated by a central dispatcher, AgentLinkHub, so their
tested sets do not overlap: "AgentLinkHub utilizes a Priority Queue to
select the agent with the maximum Q value … to make a move. If the selected
agent has already moved continuously for several steps or if its next move
has already been taken by another agent, AgentLinkHub will switch to the
most efficient agent with the highest reward per query." In the
inference phase, "multiple reinforcement learning (RL) agents collaborate,
traversing the KG while sharing trust diffusion information generated by
the LLM." A per-agent term additionally discounts an action by whether
another agent has already claimed it, so the collaborating agents actively
avoid retesting each other's nodes.

## Why it matters

Across six tasks on graphs of over 1,000 nodes, "our optimized GMRL-BD
framework can complete the untrustworthy detection for one specific LLM
with about 10-30 query interactions for these 6 tasks." The design
choice this buys is direct: instead of scoring every candidate node by an
information-theoretic criterion computed from its own content, the
selection policy exploits topological correlation between a tested node's
verdict and its neighbors' likely verdicts, so a handful of queries can
localize a boundary in a graph of thousands of candidates. The ablations
(dropping the graph-attention layer, dropping neighbor aggregation, or
falling back to depth-first search) all degrade success rate, which the
paper reads as evidence that the diffusion assumption, not merely
"explore systematically," is doing the work.

## Limits

- The mechanism is topic-level, not query-level: "the current model is
  limited to topic-based untrustworthy detection in LLMs. Future research
  should explore on enabling query-based untrustworthy detection, where
  each query can be treated as a multinomial distribution over topics."
[^c6]
- Ground truth in the paper's own benchmark (LBID) is bias intentionally
  fine-tuned into the candidate LLMs, with every untested topic defaulted
  to "trustful" rather than independently verified; the reported Bias Node
  Cover Rate is measured against that injected label set, not against an
  external audit of natural pretraining bias.
- The bias-diffusion hypothesis is an empirical bet, not a guarantee: nodes
  can be biased or trustful in ways uncorrelated with their Wikipedia-graph
  neighbors, and the paper reports this failing for some LLM/task pairs
  where interaction counts do not converge (an unverified caveat the
  authors note themselves without quantifying its frequency).
