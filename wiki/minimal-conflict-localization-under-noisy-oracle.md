# Minimal-conflict localization under a noisy oracle

Whether a set of claims can all be true is a property of the whole set, not of its pairs. Three facts A xor B, B xor C, C xor A are pairwise satisfiable yet jointly unsatisfiable (a 2-colouring of a 3-cycle), so even with a perfect oracle there are sets of size N >= 3 whose pairs are all consistent but which are inconsistent globally.[^c1] Asking an LLM about pairs therefore cannot certify consistency.

## Mechanism

The oracle is a subset-consistency judge: given a set of claims it answers "cons" or "incons", with error rates alpha and beta. The target is a minimal unsatisfiable subset (MUS), the smallest group of claims that cannot jointly hold. Any finite set judged inconsistent contains one.[^c2] Finding one uses QuickXplain, a divide-and-conquer routine: split the candidate set in two, recurse on one half with the other half as background, then on the other half with the found part as background; depth is logarithmic in the set size.[^c3] The paper's Algorithm 1 repeats this, then optionally repairs by choosing a hitting set that deletes at least one claim from every MUS found. Maximising kept facts is equivalent to minimising deletions.[^c4] Greedy hitting set is within a factor (1 + ln m) of optimal.[^c5]

Query cost: at most I * m * (k log N) oracle calls, where m is the number of constraints, k the largest MUS found and I the outer rounds.[^c6] The abstract also states that verification needs exponentially many queries in the worst case, which is why small conflict sets (small k) matter.[^c7]

Noise: if each query is repeated r times and majority-voted, the aggregated error is at most exp(-2 r gamma^2) with gamma = 1/2 - max(alpha, beta), assuming independent repetitions.[^c8] Even with a noisy oracle, the retained set is sound with respect to the MUSes actually extracted, though those may themselves be wrong.[^c9]

## Measured

On VitaminC and FEVER clusters of 30 statements with injected contradictions, the MUS-based method (QXR) was compared with a direct prompt asking the LLM for the largest consistent subset. The direct prompt "panic-prunes" large clusters once any conflict is detected; the MUS method gave substantially higher F1 across models.[^c10] On a synthetic set, direct scored P=0.515, R=0.993, F1=0.644 and QXR P=0.664, R=0.878, F1=0.724.[^c11] Chain-of-thought, decomposition, few-shot and self-consistency prompting of the direct baseline kept the same failure, high precision and low recall.[^c12]

## Limits

- Experiments used one call per query (r = 1) and no majority voting; the independence assumption behind the repetition bound is used only in theory, and repeated LLM calls are probably correlated (my inference; see [[effective-independent-votes]]).
- Test conflicts are injected, mostly size-2 MUSes (VitaminC) or claim-plus-evidence pairs (FEVER); larger, entangled conflicts were not the main test.
- The query bound depends on k and m, which are not known in advance.
- Soundness is relative to extracted MUSes, not true consistency.
