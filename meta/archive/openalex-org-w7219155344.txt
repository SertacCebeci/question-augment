Abstract
Agent developers increasingly compare prompts, tools, policies, and diagnosis algorithms through simulator-grounded verifiers.
A verifier can nevertheless make a solver comparison vacuous: if its probes or predicates encode the target identity, an exact
optimizer may appear effective without resolving any genuine ambiguity. We report such a failure in an aggregate-trace
debugger for a closed-loop decision agent. Exact minimum hitting set (MHS) and a propagation-aware greedy method returned
identical supports in 12/12 development cases and the same planted-fault recovery in 9/12. A subsequent audit found that
exact-anchor predicates produced the planted pair in 9/9 cases. After removing those anchors, overall planted-pair recovery
was 8/9; hard-probe singleton pairs nevertheless matched the planted pair in 9/9, and no case retained a nonempty residual
conflict family after propagation (0/9). The optimizer was correct, but the verifier had already disclosed the answer. We
replace solver-first evaluation with a support-gated verification contract. A clean reference map must first show repeated
component exposure; a matched reference/current gate must then establish comparable runtime evidence; only afterward
may an independently calibrated signal rule return a detection. In a preregistered heldout comprising 1,440 cases and 21,600
partition rows, 55/72 regime-component units passed the reference gate, 54/55 passed the runtime gate, and stable false
admission was 0/20 represented components with a one-sided exact 95% upper bound of 0.1391. Within admitted units, affected
clean traffic predicted detection better than nominal fault-cell fraction. The main lesson is structural: verify evidence eligibility
and non-revelation before optimizing the component selector. Otherwise a stronger solver can merely certify a stronger verifier
artifact.
Keywords: agent verification, agent debugging, diagnosability, model-based diagnosis, minimum hitting set, evaluation leakage

Introduction

Interactive-agent benchmarks have moved evaluation from
static answer matching toward execution in software, web,
database, and tool environments [1, 2, 3, 4]. This is
progress: an agent should be judged by what happens in
its environment, not only by what it says. It also creates
a second-order problem. The environment, probe design,
state abstraction, and verifier jointly determine what evidence reaches the score. When any of these mechanisms
is wrong, an optimizer can improve the reported result
without improving the underlying agent or diagnosis.
This paper studies that problem in a deliberately controlled setting. Our system is a closed-loop decision agent,
not a language model. It selects actions under changing demand and inventory conditions. We observe only
aggregate traces and try to localize a planted fault to
one or more policy components. The diagnostic pipeline
compiles aggregate discrepancies into conflicts and then
chooses a low-cost component set that intersects every
conflict. Exact MHS is a natural downstream optimizer
[5, 7]. The original development claim was that exact
MHS should improve fault localization over a weighted
greedy alternative.

A verifier must establish that its evidence is eligible and non-revealing before its score can support
an optimizer comparison.
“Eligible” means that the deployed policy actually visited the component often enough for aggregate traces to
carry information, and that reference and current observations are comparable. “Non-revealing” means that the
evaluation intervention does not encode the hidden answer through its scope or mechanics. These conditions
are distinct. More traffic cannot repair answer leakage,
and a leakage-free predicate cannot create evidence for a
component the agent never exercised.

Our setting differs from passive GDE measurements in
one crucial way: the audited hard probe is a counterfactual
intervention on a single component. That intervention
can be useful, but it also creates a leakage channel when
paired with a predicate scoped to the same component.
The agent-verification analogue is a benchmark tool that
writes the hidden label into an observable field and then
rewards the agent for reading it.
Abstention supplies the complementary idea. Selective
prediction treats refusal as a valid output when confidence
or coverage is inadequate [9]. Risk-controlling calibration
can attach finite-sample guarantees to a chosen loss [10].
We apply the same discipline upstream: the verifier abstains before diagnosis when the policy did not produce
enough matched evidence. This is not a confidence threshold on a completed prediction; it is an eligibility test on
the evidence from which a prediction would be constructed.
Dataset-shift tests and conformal change detectors provide
a related lifecycle pattern: detected reference mismatch
should trigger review or retraining rather than silently
extending the original claim [11, 12].

The heldout does not compare exact MHS with greedy
selection and does not establish localization accuracy.
That omission is intentional. Once the development audit
showed that the evidence construction did not pose a genuine residual optimization problem, a new solver contest
would have repeated the same mistake. The confirmatory
experiment instead tests whether a verifier can say when
its own evidence is usable.

3.3

The development diagnostic converts aggregate evidence
and scoped predicates into conflict sets. Given component
costs, exact MHS returns a minimum-cost component set
intersecting every conflict. Weighted greedy selection repeatedly chooses a cost-effective component and performs
the same singleton propagation.
The exact guarantee is real but conditional: it optimizes
the compiled conflict family. It does not establish that
the conflict family preserves physical ambiguity, that a
planted component is recoverable, or that exact search
improves over greedy selection on the instances actually
produced by the verifier.

The original instances were not devoid of combinatorial
structure: non-singleton conflicts comprised 55.5% of the
conflict collection, and every one of the 12 scenarios contained overlapping conflicts. Yet exact MHS and weighted
greedy still returned identical supports in all 12 scenarios.
The mechanism is simple. The predicate asks about
exactly one named component. The hard probe intervenes on exactly that component. The local response is
converted into a singleton conflict naming the planted
component. Removing an explicit anchor rule does not remove this second channel. After propagation, both solvers
inherit the same forced choice.
This diagnosis changes what “verification” means. A
conventional audit might check that the MHS implementation returns a minimum-cost hitting set and that the
greedy baseline is implemented correctly. Both checks can
pass while the scientific comparison remains empty. A

Limitations

This is one simulator, one closed-loop policy family, three
demand regimes, and 24 disjoint components. The agent
is not an LLM, and we do not claim that the exact support thresholds transfer to language-agent benchmarks.
The contribution is a verification structure and a falsified
optimizer claim, not a universal threshold.
The formal heldout confirms admission, false-admission
calibration, and traffic-indexed signal behavior. It does not
confirm planted-fault localization and does not evaluate
genuinely ambiguous residual conflict families. Exact MHS
remains a valid risk-cost optimizer when such families exist;
this study shows only that the audited verifier failed to
produce them.
The family-sufficiency bound is based on approximately
20 represented component clusters. A percentile cluster
bootstrap at that cluster count may undercover in a direction favorable to the result. The 0.0066 upper bound
has only a 0.0034-nat margin below its frozen threshold.
The refresh endpoint is a state-machine smoke test.
It reuses the same frozen reference buffer and therefore
cannot show that refresh repairs a stale map after real
drift.

The most dangerous verifier is not necessarily noisy. It
can be deterministic, reproducible, and mathematically
correct while making the scientific comparison vacuous.
In our closed-loop debugger, exact-scope predicates and
one-component interventions produced forced plantedcomponent singletons, so exact MHS never faced the ambiguity it was supposed to resolve.
We replaced that solver-first claim with a support-gated
contract that verifies whether the agent generated comparable evidence before returning a signal. The formal
heldout shows that this contract can operate with explicit
abstention, independently calibrated false admission, and
traffic-indexed power. The next optimizer comparison
should begin only after a redesigned verifier demonstrates
nonempty residual ambiguity. Reliable agent development
requires verifying the evidence generator before trusting
the algorithm that optimizes its output.
