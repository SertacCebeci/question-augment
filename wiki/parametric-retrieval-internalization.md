# Parametric retrieval

Retrieval can be moved inside the model. In retrieval-internalized generation (RING), the step that RAG performs outside the model, finding the text that bears on a question, is done with the model's own weights. The authors' thesis is that the bottleneck of injecting knowledge into parameters is search, not storage: it is "to search those weights at inference time".[^c1] RAG "augments the LLM with an external retriever", whereas RING "internalizes the retriever inside the LLM as a learned policy".[^c2]

The mechanism has three parts. The first is architectural. A dense feed-forward block becomes a sparse mixture of two experts: a Basic Expert that "preserves the original LLM weights to mitigate catastrophic forgetting", and a Knowledge Expert that holds the new corpus.[^c3] Inside the Knowledge Expert the two projections have different jobs: "Memory Down is used to store knowledge, while Memory Up is a parametric index of the stored knowledge."[^c4] A search gate works with the SiLU to "reweight indexes for different queries", so one stored memory is read out by query-dependent weights.[^c5] A learned router picks one expert per token.

The second part is inference. The model "first identifies whether new, externally injected knowledge is required", and if so it generates a top-1 fragment from the Knowledge Expert, wrapped in retrieval tags, before the answer.[^c6] The fragment is short: "The retrieved fragment is typically short (with about 200" tokens.[^c7]

The third part is training, in three stages. Continued pre-training "injects new corpora into a Knowledge Expert", using a bidirectional-style attention on the corpus.[^c8] Supervised fine-tuning teaches the search-then-answer format, and then "only update[s] the Router and Search Gate" so that the memory is not overwritten.[^c9] Reinforcement learning uses GSPO with a search reward built from longest-common-substring matches; the reward "measures the normalized longest common substring (LCS) length between the retrieved" unit and the correct one, and the answer is judged by a separate model.[^c10] The paper calls the result "a fully learned parametric retriever", unlike earlier parametric injection methods whose retrieval rule is hand-designed and frozen.[^c11]

On the authors' News-2025 benchmark with Qwen3-8B, RING "reaches 35.08%/32.36% (EN/ZH)", above the strongest prior parametric method, SR-KI, by 3.23 and 3.14 points.[^c12] By my reading of Table 1, this also clears every top-1 RAG row, while the reranked RAG pipelines stay ahead. The paper says RING "matches strong RAG pipelines in accuracy" and runs "faster than RAG at inference".[^c13]

The theory is an expressivity result. The authors show that RING's hypothesis space "contains explicit topK RAG, implying that parametric retrieval can" approximate external search, so that parametric retrieval "can theoretically match external search expressivity".[^c14] Containing a policy is not the same as learning one; the training argument is a variational bound in which the search reward stands in for the latent evidence.

## Limits

- The benchmark is the authors' own. News-2025 is "our constructed bilingual benchmark", with questions written by GPT-5 over news the base model does not contain.[^c15][^c16] The isolation from pre-training is the design's reason for existing, so numbers from this set do not transfer directly to other corpora.
- Accuracy does not dominate RAG. The strongest reranked pipeline "surpasses RING by 4.43" English points, and the paper's win is on the accuracy–latency frontier, not on accuracy.[^c17] Only two backbones are reported, Qwen3-8B and Qwen3-14B.[^c18]
- The bound is a proxy argument. The reward is claimed to serve "as a proxy" for the unobserved latent evidence.[^c19] The text does not measure how close the trained retrieval policy comes to the ideal posterior.
- One fragment per query. The design emits "the top-1 relevant fragment" and nothing else.[^c20] Questions whose answer needs several injected passages are not addressed by this design, by my reading.
- Cost is a claim about one corpus. The paper says the design "shifts retrieval computation to the training stage" and yields cost "that scale with model" size rather than index size.[^c21][^c22] Growth of the corpus with re-injection was not tested in the part of the text read.
- Faithfulness at test time is my open question. The fragment is generated by the same weights that answer. The exact-match term in the training reward checks that the reference appears, but the test-time fragment is not shown to be a copy of stored text rather than a fluent reconstruction.
