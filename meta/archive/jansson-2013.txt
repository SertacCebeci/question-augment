Citations Abstract This paper presents two new deterministic algorithms for constructing consensus
trees. Given an input of k phylogenetic trees with identical leaf label sets and n leaves each, the
first algorithm constructs the majority rule (+) consensus tree in O ( k n ) time, which is optimal
since the input size is Ω( k n ), and the second one constructs the frequency difference consensus
tree in min { O ( k n 2 ), O ( k n ( k + log 2 n ))} time. This is a preview of subscription
