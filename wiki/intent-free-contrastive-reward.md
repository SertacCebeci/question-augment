# Intent-free contrastive reward

A personalized answer is only worth reinforcing if it differs from what the same model would say without the user's intent. The IAP framework makes that difference part of the reward. For each question, a frozen reference model writes an answer without any intent conditioning, and the reward is docked for every trained answer that stays close to it.[^c1]

The penalty has two parts. The first is a semantic-similarity term: BERTScore between the trained answer and the intent-free answer, so a response that paraphrases the generic one earns less. The second is a quality-margin term: the penalty is positive when the intent-free answer's personalization score exceeds the trained answer's, so the trained answer must beat the generic one on the same rubric.[^c2] The total reward is the personalized score minus the weighted contrast term and a length term on the intent segment. The paper's own reading is that the intent-free answer creates "an intent-free baseline, or a lower bound, that the reward must exceed."[^c3]

The mechanism is a counterfactual baseline in reward space. Group-relative advantage already compares rollouts for the same question against each other. Adding the intent-free answer gives a fixed reference point outside the group. A rollout that scores well only because it is generic is still penalized, so the policy has no gain from producing a generic-but-well-rated answer. The paper states the same thing: "without the contrastive reward, the model has no reason to prefer a personalized answer over a generic one that scores equally well."[^c4]

The effect is measured by ablation. Training a model without the term lowers the macro-average score in the paper's Table 3. Reading the flattened table (my pairing of its numbers, not a figure the paper prints), the with-contrast average is higher in all six model rows; the paper's summary is "removing this component consistently degrades performance across all evaluated models."[^c5] The margin is not uniform: for Qwen2.5-7B-Instruct the average rises from about 0.418 to 0.450, and for Mistral-Small-24B-Instruct from about 0.532 to 0.595, so the gain is not confined to one model family.

## Limits

- The personalized score µ is itself an LLM judge. The paper instantiates it with "Qwen2.5-32BInstruct (Yang et al., 2024) with temperature 0.0 as the judging model."[^c6] The same judge scores both the trained answer and the intent-free answer, so a judge bias toward length or fluency enters the penalty too. The paper does not test this.
- The reference is the same base model without intent conditioning. The penalty therefore measures distance from that model's default behaviour, not from a human notion of generic. A base model that is already intent-sensitive would give a weaker contrast. This is my inference; the paper does not vary the reference.
- The ablation removes the term entirely. It does not compare alternative baselines (for example, a fixed set of generic answers, or the intent-free answer from a different model), so the claim is that some contrast helps, not that this particular contrast is best.
- Only LaMP-QA, a long-form social-question benchmark with rubric aspects, was tested. Transfer to tasks without per-question rubrics, where µ would have to be rebuilt, is not shown.
- The contrast is computed on one intent-free sample per question. The variance of that single reference is not reported.
