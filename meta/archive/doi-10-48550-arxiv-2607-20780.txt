A BSTRACT
Open-world video anomaly detection (OWVAD) aims to localize anomalous
events in videos according to a user-specified definition. An OWVAD detector
should therefore use the supplied definition to decide what is anomalous. We call
this behavior definition following, and its failure definition blindness. However, existing temporal evaluation protocols may obscure this distinction, making
strong generic anomaly detection appear to reflect definition following. For example, Drift@5 (Liu et al., 2026b) and the customizable VAD protocol (Ahn et al.,
2026) treat both normal frames and anomalies outside the current definition as
negatives. Across the three benchmarks used in our study, normal frames account for 78.6%–96.4% of these negatives. As a result, the reported score can
be driven largely by target-versus-normal separation rather than target-versusother-anomaly separation. Consistent with this diagnosis, a LaGoVAD (Liu et al.,
2026b) branch that never receives the anomaly definition nearly matches the full
model under Drift@5. We therefore introduce three complementary definitionconditioned evaluations that separate definition following from generic anomaly
detection. Applying them to VAD systems and general vision–language models
on UCF-Crime, XD-Violence, and MSAD reveals that strong performance under existing evaluation can coexist with weak definition following. Motivated
by these results, we introduce Definition-Contrastive Scoring (DeCoS), which reduces anomaly evidence shared across competing definitions and improves definition following across the three benchmarks. Our results show that generic
anomaly detection and definition following are distinct capabilities and should
be evaluated separately in OWVAD.

1

I NTRODUCTION

Video anomaly detection (VAD) aims to localize anomalous events in videos (Wu et al., 2024b;
Song et al., 2025). In conventional VAD, which events are considered anomalous is predefined in
the benchmark (Sultani et al., 2018; Wu et al., 2020; Zhu et al., 2024). Open-world video anomaly
detection (OWVAD), by contrast, allows users to specify which events should be considered anomalous (Liu et al., 2026b; Ahn et al., 2026). The detector takes this user-specified anomaly definition
as input. OWVAD therefore requires more than detecting anomalous events. For the same video,
changing the anomaly definition should change which events receive high scores. Figure 1 illustrates this distinction with separate shooting and explosion intervals. In the top row (a), changing
the definition from shooting to explosion shifts the highest scores from the shooting interval to the
explosion interval. We call this behavior definition following. In the bottom row (b), the two definitions produce nearly identical score curves, with both anomalous intervals receiving high scores.
We call this behavior definition blindness.
However, existing VAD evaluation may not clearly distinguish definition following from definition
blindness. Standard VAD metrics operate under a fixed benchmark definition and therefore do not
compare anomaly scores across different anomaly definitions. Recently introduced OWVAD evaluation protocols, such as Drift@5 (Liu et al., 2026b) and customizable VAD (C-VAD) evaluation (Ahn
et al., 2026), specify which anomaly classes are treated as targets. Yet both compare target anomalies
against a negative set that contains normal frames and anomalies excluded by the current definition.

A high score can therefore come from separating target anomalies from normal frames, even if the
model does not distinguish target anomalies from other anomalies present in the video.
We find that this imbalance is substantial on current VAD benchmarks. Across UCF-Crime, XDViolence, and MSAD, normal frames make up 87.9%–96.4% of the negative set under Drift@5
and 78.6%–93.0% under class-wise C-VAD evaluation. To test whether this imbalance can hide
definition blindness in practice, we evaluate a branch of LaGoVAD (Liu et al., 2026b) that never
receives the anomaly definition. Although this branch produces the same scores for every anomaly
definition, it nearly matches the full model under Drift@5, with gaps of only 0.6–1.2 AUROC points
and 0.3–0.5 AP points on XD-Violence and MSAD. These results reveal that even evaluation protocols with varying anomaly definitions may fail to distinguish definition following from definition
blindness. We therefore introduce three complementary definition-conditioned metrics to evaluate
definition following: DC-Disc, ∆DC-Det, and ∆DC-Sel. They test whether a model distinguishes
the specified anomaly from other anomalies, detects the specified anomaly better with the matching definition than with non-matching definitions, and selects the matching event when multiple
anomalies occur. These metrics separate definition following from generic anomaly detection.
We apply these metrics to VAD systems spanning conventional, open-vocabulary, and open-world
settings, together with general vision–language models, on UCF-Crime, XD-Violence, and MSAD.
Across our experiments, we find that models that perform well under existing VAD evaluation often
struggle to follow the supplied anomaly definition. Motivated by this gap, we introduce DefinitionContrastive Scoring (DeCoS), which scores the supplied definition relative to competing definitions
and reduces anomaly evidence shared across them. DeCoS improves all three definition-conditioned
metrics across the three benchmarks.
This study provides new insights into the evaluation of OWVAD by showing that strong generic
anomaly detection performance can mask definition blindness, even when anomaly definitions vary
during evaluation. Our core contribution is to make the distinction between anomaly detection
and definition following explicit and measurable, through dedicated evaluation metrics, empirical
analysis, and Definition-Contrastive Scoring. Together, these contributions highlight that progress
in OWVAD should be measured not only by how well models detect anomalies, but also by whether
their predictions follow the supplied anomaly definition.

R ELATED W ORK

Video anomaly detection. Semi-supervised VAD learns from normal training videos (Hasan et al.,
2016; Liu et al., 2018; Gong et al., 2019; Song & Lee, 2026a), while weakly supervised VAD
uses video-level labels to localize anomalous events (Sultani et al., 2018; Tian et al., 2021; Feng
et al., 2021; Song et al., 2025). These settings are typically evaluated under a fixed benchmark
2

definition of anomaly (Sultani et al., 2018; Wu et al., 2020; Zhu et al., 2024). Open-set and openvocabulary methods extend detection to unseen anomaly classes (Zhu et al., 2022; Wu et al., 2024a;
Xu et al., 2025; Li et al., 2025), while cross-domain and multi-domain methods study generalization across datasets and anomaly labels (Aich et al., 2023; Cho et al., 2024). These lines of work
ask whether anomaly detection generalizes to new classes or domains. We instead study whether
temporal anomaly scores follow a supplied definition.
Language-based anomaly detection. CLIP-based VAD uses image–text alignment to localize
and recognize anomalous events (Radford et al., 2021; Wu et al., 2024b; Zhu et al., 2026). Multimodal language-model methods use captions and reasoning to detect and explain anomalies (Zanella
et al., 2024; Ye et al., 2025; Zhang et al., 2025; Song et al., 2024; 2026). These approaches establish
language as a useful source of supervision or conditioning for anomaly detection. Our method uses
language for a different purpose: it constructs temporal anomaly scores relative to competing definitions and trains the readout to distinguish the matching definition from non-matching definitions.
User-defined anomaly detection and evaluation. Recent work extends VAD to user-specified
anomaly definitions (Liu et al., 2026b; Ahn et al., 2026; Liu et al., 2026a). In this setting,
Drift@5 (Liu et al., 2026b) and the C-VAD protocol (Ahn et al., 2026) assess model performance
as the user-provided anomaly definition changes. These protocols, however, do not isolate how the
supplied definition changes the ranking of anomaly scores, because their evaluations reward generic
anomaly detection more heavily than definition following. Our work separates these effects and
evaluates definition following directly.

3.1

W HY EXISTING EVALUATION MAY CONCEAL DEFINITION BLINDNESS

In this section, we show why definition-blind detectors can perform well under existing VAD evaluation. We identify each evaluation frame by i = (n, τ ), where n indexes videos Vn and τ indexes
a frame within it. We write si (z) = Sτ (Vn , z) and use s(z) to denote the collection of these scores.
All frame sets below use these indices. Let A and N denote the index sets of frames labeled anomalous and normal by the benchmark, respectively. Let m denote either the AUROC or AP evaluation
function. We write m(s(z); P + , P − ) for its value with P + as the positive set and P − as the negative
set, using their scores in s(z).
Standard VAD evaluation treats all anomalous frames as positives (P + = A) and normal frames as
negatives (P − = N ). It measures generic anomaly detection under a fixed benchmark definition.
Consider a detector that reuses the scores obtained under this definition for every definition, as in
Equation (3). Its standard VAD AUROC and AP remain unchanged despite its definition blindness.
High performance under this evaluation therefore does not establish definition following.

Normal frames dominate the negative pool under both Drift@5 and C-VAD-style evaluation on

in both protocols, target-versus-normal discrimination can contribute substantially to the reported
score even when the detector does not distinguish the target anomaly from other anomalies.

E XPERIMENTAL R ESULTS

We now test whether the distinction between anomaly detection and definition following changes
how existing VAD systems should be evaluated. We first examine how Drift@5 combines targetversus-normal and target-versus-other-anomaly discrimination. We then evaluate definition following directly across model families, test definition-conditioned selection on natural multi-event
videos, and examine whether the results depend on exact event names. Finally, we ablate DeCoS to
connect its components to the behaviors they are designed to support.
Protocol. We evaluate on UCF-Crime (UCF), XD-Violence (XD), and MSAD (Sultani et al.,
2018; Wu et al., 2020; Zhu et al., 2024). The comparison includes weakly supervised VAD, openvocabulary VAD, language-guided OWVAD, and generative vision–language models (Liu et al.,
2024; Zhu et al., 2025; Bai et al., 2025b;a). For a fair zero-shot comparison, VadCLIP, LaGoVAD,
PLOVAD, and DeCoS use the same PreVAD training source (Wu et al., 2024b; Liu et al., 2026b;
Xu et al., 2025). Model-specific inputs and scoring rules are given in Appendix C. We evaluate all
three metrics with both AUROC and AP. The main tables report AUROC for compactness, with the
corresponding AP results in Appendix D.

Definition following should be evaluated separately. Changing the anomaly definition during
evaluation is not, by itself, enough to evaluate definition following. In Drift@5 and C-VAD-style
evaluation, target anomalies are compared against a negative pool containing both normal frames
and anomalies excluded by the current definition. Because normal frames make up most of this
pool on the benchmarks we study, a detector can score well by separating anomalies from normality
even if its ranking changes little with the definition. OWVAD evaluation should therefore report
definition following separately from conventional anomaly detection.
Definition sensitivity is not definition following. A model can respond to changes in the input
text without ranking the event specified by that text more highly. Definition following therefore
requires a directional comparison: on the same visual evidence, the matching definition should rank
the matching event higher than non-matching definitions do. This is why our ∆ metrics compare
matching and non-matching definitions rather than measuring score variation alone.
The evaluated definitions remain benchmark-grounded. We evaluate definition following
across the anomaly concepts in UCF-Crime, XD-Violence, and MSAD, including settings where
the exact event name is unseen during training or removed from the test-time definition. These controls show that definition following need not depend on exposure to the exact event name during
training or its inclusion in the test-time definition. They do not establish generalization to arbitrary user definitions or entirely new anomaly concepts, since some events with unseen names are
conceptually close to those represented in PreVAD and our evaluation remains anchored to benchmark events. Evaluating definition following with more open-ended user definitions is an important
direction for future benchmarks.
Natural multi-event evaluation remains limited in scale. Our controlled two-event clips provide
a clean test of whether changing the definition changes the relative scores of co-occurring anomalous
events. We also observe the same distinction on 43 naturally multi-event XD-Violence videos, but
this subset is small and less balanced than the controlled evaluation. A larger benchmark with
naturally co-occurring anomalies and query-specific temporal annotations would allow definitionconditioned selection to be evaluated in natural videos at a larger scale.

C ONCLUSION

Open-world video anomaly detection should be evaluated by whether temporal scores follow the
supplied anomaly definition, not only by whether anomalous frames are separated from normal ones.
We show that existing temporal evaluations can obscure this distinction. Across UCF-Crime, XDViolence, and MSAD, normal frames make up 87.9%–96.4% of the negative pool under Drift@5
and 78.6%–93.0% under C-VAD evaluation. As a result, strong target-versus-normal separation
9

can contribute substantially to the reported score even when a model poorly distinguishes the target anomaly from other anomalies. Our definition-conditioned evaluation confirms this distinction
across multiple model families: strong generic anomaly detection can coexist with weak definition
following.
These findings change what should count as evidence of OWVAD behavior. Definition following
should be evaluated explicitly alongside conventional anomaly detection, rather than inferred from
text conditioning or strong target-versus-rest performance. DeCoS provides a constructive example
that definition following can be improved with definition-relative scoring. More generally, testing
how anomaly scores change when the anomaly definition changes provides a direct way to determine
whether an OWVAD system follows the supplied anomaly definition.
