# Hard-irrelevant query

A query is hard-irrelevant when it sits close to the material it is asked against and still does not fit it. In video temporal grounding (VTG) a model is given a video and a natural-language query and must return the segment the query describes. Some queries have no such segment. Jung et al. (2025) separate irrelevant queries into two kinds: those entirely unrelated to the video, which earlier refusal-capable models learned to reject, and hard ones, "semantically close to the video but not actually relevant."[^c1] Their running example is a query about a chef cutting steaks, set against a video of a chef cooking pasta. The scene and the activity match; the action and the object do not.

The distinction matters because the negatives a model is trained on decide what it learns to refuse. Earlier VTG models were trained on negatives made by shuffling queries across videos, so what they learn to refuse is what is plainly unrelated. The paper's ablation finds the same limit inside its own training: with only shuffled irrelevant queries, the model does not get better at refusing hard cases, because the signal focuses on coarse relevance differences.[^c5] A model that refuses unrelated queries well can therefore still accept a near miss, and the two abilities have to be measured separately.

The concept is that the mismatch is local. Hard-irrelevant queries "share high-level semantic context with the video but differ in specific details."[^c6] A model that matches on scene, participants and general activity will accept such a query. Refusing it means checking each element the query names against the video, so the failure is a failure of element-level comparison, not of topic detection.

Hardness is also graded by how much of the query is wrong. The paper's sets change one element (strong), two (moderate) or three (weak) of the original query, which gives "different degrees of semantic mismatch."[^c3] The reported gains are larger where the mismatch is larger: "larger gains observed in strong hard-irrelevant" cases.[^c4] This grading is what lets one ask how much of the mismatch a model can see, rather than only whether it refuses.

For asking and answering, the point is that a question can match its material in topic, wording and setting while one detail that the answer depends on is absent. An answerer who accepts the question on its topic commits to a claim the material does not support. The reading-comprehension version of this is [[adversarial-unanswerable-questions]], where the unanswerable questions were written to look answerable. Here the look-alike property is the same, and what is added is the grade of the mismatch.

The paper's remedy, post-training with format, refusal, explanation and query-correction rewards under GRPO, is a training method. This note keeps the object it targets, not the remedy.

## Limits

The grade of hardness is set by construction: the number of changed elements, not a measured distance between query and video. The paper does not report an independent similarity measure that separates its hard negatives from its shuffled ones, so "semantically close" is a property of the generator's procedure, not a measured one.

The evaluation sets were generated by the same LLM procedure as the training data.[^c7] The authors add a human-annotated set of 100 relevant and 100 hard-irrelevant cases "to avoid potential bias from using the same construction procedure for"[^c8] training and evaluation. That set is small, and the text read here does not report annotator agreement on what counts as a hard-irrelevant query.

The results are for LVLM-based VTG models at 7B scale on three benchmark families, and the ablations were run on one of them (HI-ActivityNet). The paper does not test whether the three-level grade holds for other query types, other media, or other categories of relevance beyond the eleven it defines. Whether a one-element change is harder for a human than a three-element change is not measured; the grade is by construction.
